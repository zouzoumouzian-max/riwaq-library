# حزمة رِواق الجاهزة للنشر على GitHub Pages

## محتويات الحزمة
- `index.html`: نسخة رِواق مع إضافة إعدادات التثبيت فقط.
- `manifest.webmanifest`: اسم التطبيق وأيقونته وإعدادات ظهوره كتطبيق.
- `sw.js`: خدمة التطبيق لدعم التخزين المؤقت والفتح عند انقطاع الاتصال بعد أول زيارة.
- `icons/`: أيقونة رِواق بالمقاسين المطلوبين.

## طريقة الرفع
1. أنشئي مستودعاً جديداً في GitHub باسم `riwaq` (أو أي اسم تختارينه).
2. ارفعي **محتويات هذا المجلد** إلى المستودع مباشرة، بحيث يكون `index.html` في الصفحة الرئيسية للمستودع، وليس داخل مجلد فرعي.
3. من المستودع افتحي `Settings` ثم `Pages`.
4. تحت `Build and deployment` اختاري `Deploy from a branch`.
5. اختاري الفرع `main` والمجلد `/ (root)` ثم اضغطي `Save`.
6. انتظري حتى يظهر رابط GitHub Pages، وافتحيه في Chrome على الهاتف.
7. من قائمة Chrome اختاري `تثبيت التطبيق` أو `إضافة إلى الشاشة الرئيسية`.

## ملاحظات
- يجب نشر الموقع عبر HTTPS؛ GitHub Pages يوفر ذلك تلقائياً.
- لا ترفعي ملف ZIP نفسه بوصفه الموقع؛ فكّي ضغطه ثم ارفعي الملفات والمجلدات الموجودة بداخله.
- أول زيارة تحتاج اتصالاً بالإنترنت. التخزين المؤقت لا يعني أن كل الخدمات الخارجية أو الروابط الخارجية ستعمل دون إنترنت.
- هذه حزمة PWA للتثبيت من المتصفح، وليست ملف APK ولا تنشر التطبيق في متجر Google Play.
